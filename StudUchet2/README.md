# СтудУчет — приложение классного руководителя

Настольное приложение на Python, Tkinter и PostgreSQL для хранения данных о группах, студентах и документах.

## 1. Требования

- Windows 10/11
- Python 3.10 или новее
- PostgreSQL и pgAdmin
- Microsoft Word/Excel или совместимый офисный пакет — для открытия и печати файлов

## 2. Создание базы данных

1. Откройте pgAdmin и подключитесь к серверу PostgreSQL.
2. Создайте базу данных с именем `studuchet`.
3. Откройте Query Tool именно для базы `studuchet`.
4. Если создаёте базу впервые — откройте `schema.sql` и выполните весь SQL-код. Если у вас уже есть база от предыдущей версии приложения — НЕ запускайте поверх неё `schema.sql`; вместо этого выполните один раз файл `migration_update.sql`. Он добавит таблицу специальностей и новые поля студентов, сохранив имеющиеся группы, студентов и документы.

## 3. Настройка подключения

Откройте `db.py`. По умолчанию используются:
- host: `localhost`
- port: `5432`
- database: `studuchet`
- user: `postgres`
- password: `postgres`

**Измените пароль на пароль своего пользователя PostgreSQL.** При необходимости можно задать переменные окружения `STUDUCHET_DB_HOST`, `STUDUCHET_DB_PORT`, `STUDUCHET_DB_NAME`, `STUDUCHET_DB_USER`, `STUDUCHET_DB_PASSWORD`.

## 4. Установка библиотек

Откройте терминал PyCharm в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

## 5. Запуск

```bash
python app.py
```

## 6. Использование

1. На вкладке «Специальности» добавьте специальности (название обязательно, код — необязательно).
2. На вкладке «Учебные группы» создайте группу и выберите для неё специальность.
3. На вкладке «Студенты» добавьте студентов вручную или нажмите «Импорт из Excel». Используйте файл `Пример_импорта_студентов.xlsx`; заголовки: `Номер`, `Студент`, `Группа`, `Дата рождения`, `СНИЛС`, `Телефон`, `Email`. В столбце `Студент` указывайте ФИО в порядке «Фамилия Имя Отчество», названия групп должны совпадать с группами в приложении.
3. Выберите студента и используйте «Профиль / документы» или «Загрузить документ студенту».
4. Загружайте DOCX/XLSX-шаблоны на вкладке «Шаблоны».
5. Для автоматического заполнения добавьте в шаблон плейсхолдеры, например:
   - `{{ФИО}}`
   - `{{Фамилия}}`
   - `{{Имя}}`
   - `{{Отчество}}`
   - `{{Группа}}`
   - `{{Курс}}`
   - `{{ДатаРождения}}`
   - `{{Возраст}}`
   - `{{Номер}}`
   - `{{СНИЛС}}`
   - `{{Телефон}}`
   - `{{Email}}`
   - `{{Специальность}}`
   - `{{Адрес}}`
6. Выберите студента → «Сформировать документ» → введите ID нужного шаблона.
7. Документ питания создаётся на вкладке «Учебные группы». Заполненный файл можно загрузить в «Архив».\n8. На вкладке «Архив» доступны открытие, скачивание копии, печать и удаление выбранного документа. Удаление требует подтверждения и удаляет как запись из базы данных, так и сохранённый файл.

## 7. Структура проекта

- `app.py` — графический интерфейс и бизнес-логика
- `db.py` — подключение и запросы PostgreSQL
- `documents.py` — хранение, заполнение, открытие и печать документов
- `Пример_импорта_студентов.xlsx` — пример таблицы для массового импорта студентов
- `schema.sql` — структура новой базы данных
- `migration_update.sql` — обновление базы, созданной предыдущей версией приложения
- `specialties` — отдельная таблица специальностей; специальность выбирается при создании учебной группы
- `requirements.txt` — библиотеки Python
- `storage/documents` — документы студентов
- `storage/templates` — шаблоны
- `storage/archive` — архивные файлы

## Важные ограничения текущей версии

- Поддерживаются шаблоны DOCX и XLSX. Загрузка студенческих и архивных документов также допускает PDF, DOC и XLS, но автоматическое заполнение реализовано только для DOCX/XLSX.
- Печать выполняется через приложение, зарегистрированное в Windows для соответствующего типа файла; драйвер принтера должен быть установлен.
- Возраст рассчитывается по текущей дате автоматически.
- Для DOCX плейсхолдеры рекомендуется размещать целиком в одном фрагменте текста (run), без разрыва разным форматированием.
- Перед использованием на реальных персональных данных настройте права доступа Windows, резервное копирование PostgreSQL и защищённое хранение документов.
